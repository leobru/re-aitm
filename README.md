# re-aitm

Восстановление и разбор **транслятора с автокода ИТМ** (АИТМ, в каталоге
2048 — «ТРАНСЛЯТОР С А/К И Т М»). Исходников нет; код снят с диска 2148
(на 2248 — те же зоны побайтно) и дизассемблирован. Устройство кода ИТМ,
в котором транслятор держит тексты, и сравнение с МТК-2 — в
[ITM-encoding.md](ITM-encoding.md) (таблица — `itm-encoding.txt`).
Библиотеки текстов (МЛ30/МЛ31, ключ `Л`, разделы `Б;`) и модулей
(том 067, ключ `Р`) — в [LIBRARY.md](LIBRARY.md), открытые вопросы — в
[TODO.md](TODO.md).

Пометки: **[трасса]** — проверено потактовой трассой dispak, **[опыт]** —
проверено заданием, **[код]** — прочитано в коде.

## Как вызывается

Колода (`jobs/aitm.b6` — пример из `besm6.github.io/wiki/examples/autocode-itm.b6`,
переведённый на 2148) объявляет `ФИЗО МБ21` и `ЛЕНТ 40(2148)`: физический
барабан 21 задачи — это 2148 со сдвигом 0400, **зона барабана N = зона
2148 0400+N** [трасса]. Загрузчик с 04237:

```
В 4237
K 00 070 4245                 Э70: лист 020000 -> барабан 23, зона 0
К 00 010 4243 00 050 0112     Э50 0112 с параметром 4243
К 00 070 4244                 Э70: 0411.1 (барабан 21, зона 011, сектор 1) -> 06400
К 00 010 0003 00 30 06770     ПБ 06770 - загрузчик в резиденте
С 0000 0000 0040 0010
С 4014 0301 0021 0111
C 0000 1000 0023 0000
В 20000                       текст программы на автокоде с 020000
```

Остальные колоды — `jobs/w1.b6` (то же без листинга), `w2` (ошибки в
тексте), `w3` (маленькая программа, печатает «ПРИВЕТ ВСЕМУ»), `w5`
(разделы констант `С;`, `Ч;`, `Л;`, ошибки 05 и 52) и тесты покрытия
(ниже).

## Тесты покрытия

Колоды `jobs/*.b6` после `w5` написаны, чтобы исполнить код, до
которого не доходили задания выше. Синтаксис — по инструкции
«Автокод БЭСМ-6» (ИТМ и ВТ, 1969; `besm6.github.io/doc/Автокод-Чайковского.txt`)
и по коду; ключи стоят перед `В;` и читаются по одной литере (`КЛЮЧИ`).

| Задание | Что проверяет | Чем кончается |

| `sb1` | `ЛСЛОВА.ЗАПИСЬ,` с `ЛЕНТ 30(2222-ЗП)` на обнулённом томе — текст `СЛОВА` в библиотеку | «А-П. ЗАПИСЬ МЛ30 СЛОВА» |
| `sb2` | `ЛПЕЧ.ЗАПИСЬ,` на томе `sb1`, в тексте `Б;СЛОВА,` | «А-П. СБОРКА МЛ30 СЛОВА», «А-П. ЗАПИСЬ МЛ30 ПЕЧ»; на ленту записан текст уже со вставкой |
| `sb3` | `Б;ПЕЧ,` на томе `sb2` | «А-П. СБОРКА МЛ30 ПЕЧ», «ПРИВЕТ ВСЕМУ» |
| `sb4` | `Б;ПЕЧ,ПЕЧ,` — имя дважды | текст вставлен дважды: ошибки 25 (метки `ИС`, `Т1`, `Т2`), 00 |
| `sb5` | `Б;НЕТУ,` — имени нет в каталоге | «ОШИБКА А-П.», ошибка 00 |

Найдено при этом:
- в прокрутке `Э20`, `Э21` (экстракоды 0200/0210) и `Э32`, `Э33`
  (`выпр`, `стоп`) — запрещённые команды (ошибка 00); двузначный код
  после `Э` — код длинной команды как есть, трёхзначный — короткой;
- интервалы прокрутки и печати пишутся `блок-метка` (`1-НАЧ`), просто
  метка — ошибка 72;
- ключ `Р` понимает литеры W, А, Н, Г, К, `,` (имя), `(` и `!`;
  `Р…,Б(1)!` портит информационное слово обмена;
- задания `lib*` — цепочка: каждое начинает с тома 067 предыдущего
  (`VOLIN`/`VOLOUT` в `tools/trace.sh`), разбор тома — `traces/libN.lib`
  (`tools/vol.py`); формат каталога и модуля — в [LIBRARY.md](LIBRARY.md);
- в модуль попадают адреса от 010 до счётчика размещения, поэтому
  программа для библиотеки начинается с 010 и не кончается `Н;НАЧ,`;
- `Ф12ПЕЧ,…` без запятой после числа зацикливается на «ОШИБКА В
  ИМЕНИ» до снятия — в тесты не вошло;
- задания `sb*` — цепочка на томе ленты 30, как `lib*`; `sb1` начинает
  с обнулённого тома `traces/zero.vol` (незаписанный том читается
  заполнителем 2525…, и `Б;` на нём не кончается за 60 с). Имя и режим
  в ключе `Л` разделяются любым небуквенным знаком (`ЛПЕЧ.ЗАПИСЬ,`):
  пробелы пропускаются, и `ЛПЕЧ ЗАПИСЬ,` — одно имя; `Л ПЕЧ…` — «ОШИБКА
  В ИМЕНИ». Текст с ошибками на ленту не пишется (`Л10,` при ошибке 06);
- `Б;ИМЯ,ИМЯ2,…` — список имён; текст из библиотеки вставляется на место
  раздела без своих внешних `В;`…`Е;`, так что его метки входят в
  объемлющий блок. Переход на следующий лист при вставке (05604–05606)
  не достигнут: текст в 60 строк умещается в лист, в 120 строк ломает
  запись (ошибки 02, 11 до снятия).

`tools/covgain.py` показывает по частям, сколько слов исполнило каждое
задание и сколько из них — только оно (`-v` — какие).

## Карта загрузки [трасса]

Снята `tools/trace.sh` + `tools/phases.py` (`traces/*.ev`); адреса — где
стоит `Э70`, сектор — четверть зоны (256 слов). Все информационные слова
обменов с барабаном 21 лежат в резиденте, 06760–06777 [код].

| Фаза | Кто грузит | Зона 2148 → адрес | Часть |
|---|---|---|---|
| загрузка | 04241 (колода) | 0411.1 → 06400 | `aitm6` |
| | 06771 | 0406 → 0, 0407 → 02000, 0410 → 04000, 0411.0 → 06000 | `aitm0`, —, `f1a`, `f1b` |
| фаза 1 | — | | `aitm0`, `aitm6`, `f1a`, `f1b` |
| смена фаз | 04013 (`f1a`) | 0407.1 → 06000, затем `ПБ 01607` | `f2b` |
| | 01607 (`aitm0`) | 0412 → 04000 | `f2a` |
| фаза 2 | — | | `aitm0`, `aitm6`, `f2a`, `f2b` |
| | 06040 (`f2b`) [код] | 0407.2 → 05000, 0407.3 → 05400, `ПБ 05035` | `f2c` |
| | 06521 (`aitm6`) [трасса lib6] | 0414 → 0, `ПБ 011` (на 2148 0414.0–2 нулевые — исполнение уходит в данные `z14`) | `z14` |

Листы 02000–03777 после загрузки — окна пейджера: в них подкачиваются
зоны барабана 23 (`u23:0`) и откомпилированная программа (`u20:30`);
0407, прочитанная туда при загрузке, — только начальное содержимое [трасса].
`f2c` грузится только при прокрутке (ключ `О`, задания `dbg`, `dbge`);
в `ЗАВЕР` решает `КОНЗАД` (06475): не ноль — конец задачи (`Э74`), ноль
(ключ `Р` со списком в скобках) — 0414 в лист 0 и `ПБ 011` [трасса lib6].

Зоны, не вошедшие в части:

| Зона | Что там |
|---|---|
| 0407.0 | лежит в 02000 только как начальное содержимое окна пейджера; отдельно не грузится, не исполнялась |
| 0411.2–3 | код, который пишет зоны барабана 012 (из 04000) и 011 (из 06000) обратно — по-видимому, сохранение/генерация транслятора; ни одного `Э70` на эти сектора, адрес загрузки неизвестен [код] |
| 0413 | пусто (нули) |
| 0414.0–2 | нули |

Слово 0 зон 0406, 0407 и 0410 — одна и та же метка `7727070700000000`;
в 04000 (`f1a`) на неё есть ссылки, в 0 (`aitm0`) она пропадает: ячейка 0
памяти всегда нулевая [код].

## Части и обратная сборка

`parts.txt` делит код на непрерывные куски — зоны или сектора
(`ЗЗЗЗ.С`) подряд с адреса части:

| Часть | Модуль | Адрес | Зоны | Исполнялось адресов |
|---|---|---|---|---|
| `aitm0` | `АИТМ0` | 0 | 0406 | 640 |
| `aitm6` | `АИТМ6` | 06400 | 0411.1 | 36 |
| `f1a` | `ФАЗ1А` | 04000 | 0410 | 649 |
| `f1b` | `ФАЗ1Б` | 06000 | 0411.0 | 205 |
| `f2a` | `ФАЗ2А` | 04000 | 0412 | 723 |
| `f2b` | `ФАЗ2Б` | 06000 | 0407.1 | 170 |
| `f2c` | `ФАЗ2В` | 05000 | 0407.2–3 | 310 |
| `z14` | `ЗОН14` | 01400 | 0414.3 | 0 |

`make check`: каждая `parts/ИМЯ.be` транслируется БЕМШ (с диска 2048),
все части линкуются одним заданием РВС по своим адресам и сравниваются
с секторами 2148 — **все 8 частей совпадают побайтно**. РВС пишет образ
по `ЗОНГП` от границы листа, поэтому часть с адреса 06400 или 05000
вырезается из зоны со своего смещения; слово 0 образа с адреса 0 не
сравнивается (там метка зоны, см. выше).

**Связи между частями — через `ВНЕШ`/`ВХОД`**, как в re-bemsh: список
`USES` в `notes/ИМЯ.py` — части, стоящие в памяти вместе с этой по карте
загрузки:

| Часть | `USES` |
|---|---|
| `aitm0`, `aitm6` | друг друга |
| `f1a`, `f1b` | `aitm0`, `aitm6` и друг друга |
| `f2a`, `f2b`, `f2c` | `aitm0`, `aitm6` и две другие части фазы 2 |
| `z14` | — |

Адрес `'ааааа'` внутри такой части становится её меткой
(`Gааааа`/`Dааааа`), после заголовка — `МОДУЛЬ ВНЕШ ИМЯ,…`, у
владельца — `ВХОД ИМЯ,…`. Адреса резидента в 04000–06377 и ссылки на
оверлеи другой фазы остаются числами. Связи найдены по адресам, без
разбора смысла: литерал, который на деле число (а не адрес), тоже станет
именем — такие исключаются списком `NOTADDR` в заметках.

Текст в коде ИТМ (`SYMS` с типом `M` в заметках, плюс эвристика
`disbesm6`: шесть байтов ИТМ, из них не меньше четырёх букв — тогда
с пометкой `возм.`) пишется как `КОНД В'…'` с комментарием `ITM '…'`:
литералов в коде ИТМ у БЕМШ нет. Отмеченные тексты: 01112 «ОШИБКА»,
06057–06067 (`f2b`) заголовок листинга «АВТОКОД … БЛОК … N … ЛИСТ»,
06322–06341 (`f1b`) сообщения редактора («ОШИБКА 00», «ИСПРАВЛЕНИЕ»,
«ЗАГОЛОВОК», «МНОГО ИСПРАВЛЕНИЙ», «СБОЙ РЕДАКТОРА», «В ТЕКСТЕ ОШИБКА»),
06650–06672 (`aitm6`) «МЛ31, МЛ30, ЗАПИСЬ, ЧТЕНИЕ, ИЗМЕН., СБОРКА,
ОШИБКА, А-П.», «ОШИБКА В ИМЕНИ».

Найдено при этом:
- `z14` — не код: таблицы 12-разрядных кодов (`1400`, `3004`, `6400`…),
  остаток работы в рабочей зоне. Принятый за код, он не собирается:
  `Э66` в **правой** половине слова (01535), а БЕМШ ставит `Э66` только
  в левую [опыт].
- Начало зоны 0410 частью повторяет начало 0406: совпадают слова 0, 1, 5,
  6, 7 (`в'02070006'`), 011 и 012 — общий заголовок зон.
- Код `f2b` при загрузке лежит в 02400–02777: блок, начинающийся в
  02473 в образе фазы 1, — это 06073 фазы 2.

## Подпрограммы

Границы и назначение подпрограмм — `NAMES` и `BLOCK` в `notes/*.py`
(212 имён), в `.be` — комментарии `*` перед каждой; пометка (ТРАССА)
или (КОД) — исполнялась ли подпрограмма хоть в одном задании
(`parts/ИМЯ.cov`, не общий счётчик трассы: адреса фаз 1 и 2 совпадают).

- **Резидент** (`aitm0`, `aitm6`): лексер `ЛЕКС` (имя/восьмеричное
  число/ограничитель в 0630/0632; ячейка 1 `РЕЖЧТ` — текст в ‘…‘ как
  комментарий, в кавычках, сырой), пейджер `ОБМЕН` по слову 0712 с
  окнами 02000–03777 и обёртками `ЗПВ0`, `ЗПВ1`, `ЧТВ1`, `ЧТВС`,
  `ЗПВС`, `ОБМВ`; поиск имени `ИЩИМ`; печать строк и листинга
  (`ВЫВЛ`, `ПЕЧСТР`, `ЛИСТИН`); `ОШИБ` — «ОШИБКА NN» и продолжение
  по таблице 12-разрядных адресов `ТОШПР`; `ФАЗА2` — смена фаз;
  в `aitm6` — загрузчик `ЗАГР`, работа с МЛ (`ТМЛ`, `ПЕЧМЛ`) и
  завершение `КОНЕЦ6`/`ЗАВЕР`.
- **Фаза 1** (`f1a`, `f1b`) — редактор, макропроцессор и построение
  таблиц. Перед текстом — ключи (`КЛЮЧИ`, 04775): И, В (начало
  текста), _, Л, П (листинг → ячейка 010), М, К, С, Р, Ф, О, Т; колода
  начинается с «ПВ;». Сообщения редактора — `ТОШ1`. Глубина вложения
  `В;…Е;` — в 04007. Ключи и разделы `Д`/`М` проверяют тесты покрытия;
  не исполнялись чтение с МЛ (`ЧТМЛ`, `ЗПМЛ`) и `ИЩ12` (см. [LIBRARY.md](LIBRARY.md)).
- **Фаза 2** (`f2a`, `f2b`, `f2c`) — проходы (номер в 0166, ключ О
  даёт 2 → `f2c`), разделы по букве в 0633 (`КЛАСС2`/`РАЗД2`):
  К `РАЗДК`, Ш 04643, В `РАЗДВ2`, Е `РАЗДЕ`, Н `РАЗДН`, С 05247,
  Ч `РАЗДЧ`, А `РАЗДА`, Т `РАЗДТ`, У `РАЗДУ`, прочие — `РАЗДЛ` (`f2b`).
  `ФИНАЛ` копирует 05316–05341 (`ПУСКЗ`) в 1–031 и делает `ПБ 1` —
  запуск программы. `f2c` — прокрутка (интерпретатор), ключ `О`.

Служебные слова (разделы) `<буква>;` — раздел действует до следующего
служебного слова; «рук.» — пункт руководства 1969 г.:

| Слово | Назначение | Обработка | Источник |
|---|---|---|---|
| `К;` | команды: пара `ИР КОП адрес = ИР КОП адрес ,`; ИР — число или описанное имя с точкой (`R3.ПВ…`) | `РАЗДК` (`f2a`) | рук. 4.2; имена регистров [опыт] |
| `Ч;` | десятичные числа (`1.5`, `-2.5 10 3`) | `РАЗДЧ` (`f2a`) | рук. 4.1.1 |
| `С;` | восьмеричные числа | 05247 (`f2a`) | рук. 4.1.2 |
| `Ш;` | шестнадцатеричные числа: цифры 0–9 и латинские A–F (таблица 01565 «FEDCBA»); `Ш;Т2:20938E908795,` — « ВСЕМУ» | 04643 (`f2a`) | в рук. нет; `hex` |
| `А;` | ровно 6 литер в слово | `РАЗДА` (`f2a`) | рук. 4.1.3.1 |
| `Т;` | текст до знака конца информации, по 6 литер в слово | `РАЗДТ` (`f2a`) | рук. 4.1.3.2 |
| `Л;` | сложная (логическая) константа из битовых полей (`Д15/26=В010/16=С777`) | `РАЗДЛ` (`f2b`) | рук. 4.1.4 |
| `Н;` | значение счётчика размещения; последний `Н;` — адрес пуска | `РАЗДН` (`f2a`) | рук. 4.4.1, 3.3 |
| `В;` | начало блока (метки внутри локальны); за ним — описания `ИМЯ=адрес,`, в т. ч. последовательные (`R1=3,R2,R3,`) | `РАЗДВ1` (`f1a`), `РАЗДВ2` (`f2a`) | рук. 4.4.2–4.4.3 |
| `Е;` | конец блока; последний `Е;` — конец текста, за ним `!` | `КОН1` (`f1b`), `РАЗДЕ` (`f2a`) | рук. 4.4.2 |
| `У;` | режим кодировки констант `А`/`Т`/`Л`: 0 — автокодовская, 2 — стандартная со склеиванием, 4 — без склеивания; в коде ещё признаки печати | `РАЗДУ` (`f2a`) | рук. 4.4.5 |
| `Д;` | определение макро `Д;ИМЯ,Ф1=Ф2=…,В;…Е;` (ключ `М`) | `РАЗДД` (`f1b`) | в рук. нет; `macro2`–`macro4` |
| `М;` | вызов макро `М;ИМЯ,А1=А2=…,` (ключ `М`): тело из `Д` с подстановкой фактических по порядку | `РАЗДМ`, `ОПМ` (`f1b`) | в рук. нет; `macro2`–`macro4` |
| `R;` | ставится фазой 1 перед текстом вызова `М;`; в фазе 2 ошибок не даёт | `РАЗДМ` (`f1b` 06066) | [опыт] |
| `Б;` | сборка из библиотеки текстов МЛ30: `Б;ИМЯ,…` вставляет тексты на место раздела (см. [LIBRARY.md](LIBRARY.md)) | `РАЗДБ` (`f1a`) | `sb1`–`sb5` |

Ветвления по символу сделаны цепочками `нтж`: в ячейках лежат не коды
литер, а маски (0306 = 045 `;`, 0307 = 046 `,`, 0360 = 057 `=`,
0313 = 064 `‘`, 0317 = 0223 В …), код проверяемой литеры — накопленный
xor по цепочке [код].

Устаревший код прежних версий резидента: `aitm6` 06710–06757 — код
для 0710–0757; `f1b` 06342–06354 (`СТАРК`) — код для 0342–0354, его
данные 06355–06377 совпадают с `aitm0` 00360–00403 [код].

Ссылки на резидент трёхзначными литералами (`'223'`) остаются
числами: `mkbe.py` переводит в имена только 4–5-значные.
